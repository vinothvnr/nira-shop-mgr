# LogBook v1

A simple static log-entry web app.

## Included in v1

- Log Type dropdown
- Description
- Status dropdown
- Automatic timestamp for every new log
- Edit/delete
- Search
- Basic dashboard counters
- Browser local storage
- Responsive mobile/desktop UI

## Run locally

Open `index.html` in a browser.

For GitHub Pages:

1. Create a GitHub repository.
2. Upload all files.
3. Go to Settings -> Pages.
4. Select the `main` branch and `/root` folder.
5. Save.
